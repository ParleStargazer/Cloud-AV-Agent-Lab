# 2026-05-07 日报

## 项目课题

本项目是“基于 AI Agent 的带杀软环境病毒样本自动化测试分析”。目标是在云端隔离 Windows 虚拟机中安装不同杀软，通过本地 Agent 编排云端测试流程，实现样本云端投递、运行监控、日志采集、拦截识别、环境恢复和结构化报告生成。

本地仍只负责流程开发、配置管理和结果分析，不保存、不下载、不执行病毒样本。

## 今日进展

- 复查当前项目状态，确认已完成本地编排框架、配置解析、安全校验、报告模板、统一网络客户端、临时代理配置和腾讯云适配器骨架。
- 根据实际申请的云主机类型，确认资源不是腾讯云 CVM，而是腾讯云 Lighthouse。
- 对照腾讯云 Lighthouse 官方 API 文档，确认 Lighthouse 的实例接口域名为 `lighthouse.tencentcloudapi.com`，实例 ID 形态为 `lhins-...`。
- 将项目中原先按 CVM 处理的假设统一替换为 Lighthouse：
  - `provider` 从 `tencent-cloud-cvm` 改为 `tencent-cloud-lighthouse`。
  - API endpoint 改为 `https://lighthouse.tencentcloudapi.com`。
  - 示例实例 ID 改为 `lhins-...`。
  - 适配器类改为 `TencentCloudLighthouseAdapter`。
  - 工厂适配器支持 `tencent-cloud-lighthouse` / `lighthouse`。
  - 快照回滚 action 从 `RollbackSnapshot` 改为 Lighthouse 的 `ApplyInstanceSnapshot`。
  - `VMOperationResponse.provider` 改为 `tencent-cloud-lighthouse`。
- 同步更新 README、架构文档、开发文档、日报和测试用例，避免继续混用 CVM 与 Lighthouse 概念。
- 重新生成报告模板，确保输出中的云厂商信息也切换为 Lighthouse。
