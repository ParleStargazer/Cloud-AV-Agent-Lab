# 2026-04-26 日报

## 项目课题

本项目课题是“基于 AI Agent 的带杀软环境病毒样本自动化测试分析”。目标是在云端隔离 Windows 虚拟机中安装不同杀软，对已授权样本进行自动化投递、运行监控、日志采集、杀软拦截识别和报告生成，并在每个测试用例结束后恢复干净快照，保证多轮测试环境一致。

本地开发环境只负责自动化流程编排、配置管理、结果分析和报告生成，不保存、不下载、不执行病毒样本。
