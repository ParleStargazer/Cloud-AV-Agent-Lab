# 2026-04-29 日报

## 项目课题

本项目是“基于 AI Agent 的带杀软环境病毒样本自动化测试分析”。目标是在云端隔离 Windows 虚拟机中安装不同杀软，通过 AI Agent 编排样本投递、运行监控、日志采集、拦截判定和报告生成，并在每个测试用例后恢复干净快照，保证多轮测试环境一致。

本地只做自动化流程开发、配置管理和报告分析，不保存、不下载、不执行病毒样本。

## 今日进展

- 完善腾讯云 CVM 适配器骨架，预留云主机开机、关机、重启、实例状态查询、快照回滚和截图产物引用接口。
- 增加 `mock / real` mode 切换，当前真实腾讯云 API 签名尚未接入，`real` 模式仍可通过 dry-run 安全验证调用计划。
- 定义统一的 `VMOperationResponse` 返回结构，包含 `status`、`task_id`、`message`、`action`、`params`、`dry_run` 和 `provider`，保证 mock 与后续 real 模式返回形态一致。
- 增加腾讯云鉴权解析逻辑，支持 `TENCENTCLOUD_SECRET_ID`、`TENCENTCLOUD_SECRET_KEY`、`TENCENTCLOUD_REGION` 等环境变量优先于配置文件。
- 增加实例 ID 覆盖逻辑，支持 `TENCENTCLOUD_INSTANCE_ID` 和带 VM ID 后缀的实例变量，方便开发阶段临时切换云主机。
- 引入 dry-run 安全机制，开启后会拦截云资源写操作，并输出 `[DRY-RUN] Would call: ...` 调用计划。
- 增加统一异常基础类 `CloudProviderError`，为后续真实腾讯云 API 错误处理做准备。
- 完善临时代理方案，确保腾讯云 API 和后续 Guest Agent 网络访问都通过统一 `NetworkClient` 读取代理配置，默认关闭，正式交付时可删除或关闭。
- 新增和更新测试，覆盖代理开关、网络客户端构建、腾讯云适配器初始化、环境变量注入、实例 ID 覆盖，以及 real+dry-run 不触发真实调用。
- 新增 `docs/DEVELOPMENT.md`，整理开发环境、配置文件、腾讯云凭据、适配器结构、dry-run、代理、Guest Agent 接入方向和验证命令。
