# 基于AI Agent的带杀软环境样本自动化测试分析

## 课题背景

基于AI Agent的带杀软环境样本自动化测试分析。
主要是想利用 AI Agent 实现，把已知有恶意行为的样本传到有带杀软的环境中运行，检查各个杀软能否检出该样本的恶意行为，有检出的杀软检出的行为是否准确。
测试机可以是云上Windows 虚拟机，或者本地的 VMware。因为每个样本对测试机造成的破坏不同，为避免影响其他样本的测试结果，要求能够实现测试环境在每个样本测试完成后实现自恢复。例如云上虚拟机恢复快照，本地 VMware 恢复镜像。

## 实现目标

1. 打通 AI Agent 全流程，实现带杀软环境下的样本自动化测试：
   支持对X 个 XX 攻击类别样本进行自动化测试，完成样本投递、运行监控、日志采集、杀软拦截行为识别的闭环
2. 对杀软拦截能力的判断，支持日志级拦截识别（含 UI 自动化识别、本地日志采集两种方式），并能对样本持久化、提权等关键攻击行为进行自动化判定，相关能力可封装为可复用 skill
   实现 VMware 虚拟机自动化镜像恢复能力，支持每次自动化测试后一键恢复初始环境，保障多轮测试的环境一致性
3. 针对腾讯管家漏检、竞品（火绒 / 360）检出的样本，实现竞品拦截点自动化分析，明确竞品检测的关键攻击行为，并生成结构化分析报告
4. 输出可量化测试结果：统计各杀软对目标攻击类别的检出率（XX%），并识别出X 个 “竞品可拦截但管家无法拦截” 的样本场景，分析并还原竞品的核心拦截规则

## 量化标准

1. 实现打通 AI agent 实现自动化测试分析样本的流程，成功测试 X 个 XX 攻击类别的样本，其中各个杀软的检出率分别是XX%。
2. 发现了 X 个拦截点是竞品可拦截但管家无法拦截的，且探究出竞品可能的拦截规则

## 能力需求

1. 熟悉各类杀软告警机制、日志存储方式及差异点
2. 具备攻击阻断判定逻辑设计能力，可将攻击成功与否与拦截效果等价关联
3. 掌握控制变量法，能独立完成竞品及内部产品拦截方式探究
4. 熟悉AI Agent工作流设计，可实现被检出的病毒样本变量自动化探索
5. 具备被检出的病毒样本分析能力，能基于自动化探索结果输出规范分析报告
6. 了解端侧用户安全需求场景，能确保测试判定逻辑贴合实际使用场景
7. 具备自动化测试分析优化能力，可应对多产品评测场景下的定位挑战

# 大白话：

想要测试几个杀毒软件谁的效果更好，但是一个个手测、还原环境太麻烦，因此要做一个自动化的AI Agent，实现：

1. 把收到的病毒自动扔进装了杀毒软件的虚拟机
2. 看各个杀毒软件有没有执行杀毒操作
3. 如果出现了不同效果，让AI分析为什么有的能检测并清除病毒，有的不能
4. 自动输出本轮测试的报告，记录现象、分析原因、给出建议
5. 测完一轮，全部自动恢复环境，准备下一轮测试。
